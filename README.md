# Сеть дронопортов России — Ковтунов Сергей Сергеевич

Код и данные для воспроизведения расчётов по планированию сети пассажирских дронопортов на три года.

## Запуск
Python >= 3.11. Из папки проекта:
```
python -m pip install -r requirements.txt
python code/check_solution.py
python code/model.py
```
Основной расчёт пересоздаёт CSV и JSON в results; время зависит от компьютера.
Графики в папке figures отражают приложенный сохранённый запуск.
Для просмотра Project.ipynb нужен Jupyter.

Источники и условия использования данных описаны в [data/sources.md](data/sources.md).

## Быстрый сценарий на защите
```
python code/check_solution.py --range 160
python code/check_solution.py --demand-scale 1.3
python code/check_solution.py --disable-node 1
```
Это оценка фиксированного плана, а не новое размещение портов.
Для нового планирования: python code/model.py --budget 800 --range 160
Параметр --budget задаёт ежегодный транш в миллионах рублей.
Быстрый пересчёт с сокращёнными лимитами: python code/model.py --quick

## Файлы
- data/raw — исходный срез выбранных областей и букв.
- data/processed — полный допустимый перечень, 30 узлов, матрицы спроса, журнал.
- results — планы, пассажирские потоки, шаблоны, расписание, эксперименты.
- figures — карты допустимых узлов и сети по годам, расписание и бюджет.
- parameters.json — параметры сохранённого запуска. Значения по умолчанию в code/model.py.
- code/model.py — расчёт и эксперименты; code/check_solution.py — проверка.

## Ограничения
Спрос синтетический. Население историческое, период 2020. Стоимости и технические
параметры учебные. Используются только маятниковые шаблоны с одним/двумя участками.
Пересадки между разными маршрутами не реализованы. Границы MILP относятся к этому классу.
Робастный выбор сделан среди 12 планов. В стресс-тестах назначения дронов фиксированы.
Воздушные зоны, погода, административный доступ и реальные разрешения не моделируются.
Выводы полной модели и отдельных небольших экспериментов не смешиваются.
Генеративный ИИ использован для подготовки кода, пояснений и оформления.
